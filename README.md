# Marée basse 🐟

**Marée basse** est un générateur de menu hebdomadaire pescétarien : 14 repas par semaine (7 recettes cuisinées en double, pour 4 portions chacune), pensés pour environ 750 kcal maximum par portion avec 200 g de légumes, ~40 g de protéines et un féculent à IG bas.

## Fonctionnalités

- **Génération automatique** de la semaine avec verrouillage des recettes à conserver
- **Fiches recettes** détaillées (ingrédients, étapes, macros par portion)
- **Liste de courses** groupée par rayon, avec quantités calculées pour 7 recettes × 4 portions
- **Réglages personnalisables** : proportion de recettes aux légumineuses, poêlées surgelées, quantité de féculent, source de protéines, ingrédients à éviter, jour de début de semaine
- **Export PDF** de la semaine, des recettes et de la liste de courses
- Fonctionne entièrement côté client, sans backend — les préférences sont sauvegardées localement dans le navigateur

## Utilisation

Ouvrir simplement `index.html` dans un navigateur, ou consulter la version publiée via GitHub Pages.

## Développement

Application HTML/CSS/JS autonome, sans dépendance ni étape de build.
